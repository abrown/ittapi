# DEPRECATED

This crate has been split into two separate crates:
 - use the [ittapi-sys] crate instead for the low-level C bindings
 - use the [ittapi] crate for high-level ITT APIs

See the [ittapi repository] for the latest updates.

[ittapi-sys]: https://crates.io/crates/ittapi-sys
[ittapi]: https://crates.io/crates/ittapi
[ittapi repository]: https://github.com/intel/ittapi
